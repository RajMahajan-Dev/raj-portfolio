# Raj Mahajan — AI & Robotics (Framer site)

Portfolio website built by Raj in Framer and published at
https://charismatic-tournaments-342744.framer.app/

This repository holds the **complete published output** of that Framer site
(HTML, JavaScript, images, fonts) as a static site, so it can be hosted
anywhere — here it deploys on Vercel.

## What is in here

- `index.html` — the portfolio homepage (About, Education, Experience,
  Projects, Research, Skills, Achievements, Contact)
- `how-it-works.html`, `agents.html`, `pricing.html`, `contact.html`,
  `blog/`, `changelog/` — pages carried over from the Framer "Cursor"
  template the site was built on
- `framerusercontent.com/` — all images, fonts and JavaScript the pages
  load (self-hosted copy of the Framer CDN assets)
- `sitemap.xml`

## Editing

Framer does not export editable source code. To change this site, edit it
in Framer, re-publish, then re-download the published site and replace the
files in this repository.

## Deploy

Static site — no build step. Vercel serves the repository root directly.
